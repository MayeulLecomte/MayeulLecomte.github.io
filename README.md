# Mayeul Lecomte — site perso

Site vitrine statique : https://mayeullecomte.github.io

- `index.html` — la page entière (HTML + CSS + JS, aucun build)
- `assets/mayeul.jpg` — portrait
- `assets/og.jpg` — image affichée quand le lien est partagé

## Modifier le site

1. Édite `index.html`.
2. `git add . && git commit -m "maj" && git push`
3. En ligne une minute plus tard.
